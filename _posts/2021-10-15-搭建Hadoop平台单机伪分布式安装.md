这篇笔记记录在 CentOS 7 最小化系统上搭建 Hadoop 单机伪分布式环境的完整过程。内容包括网络配置、基础环境准备、JDK 安装、SSH 免密登录、Hadoop 配置、HDFS 初始化和 Web 页面验证。

## 环境说明

| 项目 | 配置 |
| --- | --- |
| 操作系统 | CentOS 7 最小化版本 |
| 节点名称 | `node01` |
| JDK 版本 | `jdk1.8.0_111` |
| Hadoop 版本 | `hadoop-2.7.3` |
| 安装目录 | `/opt/bigdata` |
| 部署模式 | 单机伪分布式 |

## 一、安装 CentOS 7 最小化版本

安装 CentOS 7 时选择最小化安装即可。系统安装完成后，先检查网络是否正常，再进行后续配置。

## 二、配置网络环境

### 1. 修改虚拟机网段

在 VMware 中依次进入：

```text
虚拟机 -> 编辑 -> 虚拟网络编辑器 -> NAT -> DHCP 设置
```

在这里可以设置动态 IP 的起始地址范围。

### 2. 查看网络地址

```bash
ip addr
```

如果没有看到网卡 IP 地址，进入网卡配置目录：

```bash
cd /etc/sysconfig/network-scripts
```

编辑网卡配置文件。文件名可能是 `ifcfg-eth33` 或其他类似名称，以实际机器为准：

```bash
vi ifcfg-eth33
```

将开机启动网卡设置为：

```ini
ONBOOT=yes
```

重启网络服务：

```bash
systemctl restart network.service
```

再次查看 IP：

```bash
ip addr
```

## 三、使用 Xshell 连接虚拟机

网络正常后，可以使用 Xshell 连接虚拟机。连接后先安装常用编辑器：

```bash
yum install -y vim
```

## 四、准备基础环境

### 1. 设置主机名

编辑主机名文件：

```bash
vim /etc/hostname
```

修改为：

```text
node01
```

### 2. 配置主机名和 IP 映射

编辑 hosts 文件：

```bash
vi /etc/hosts
```

添加：

```text
192.168.243.11 node01
```

> IP 地址需要根据自己的虚拟机实际地址修改。

### 3. 关闭防火墙

```bash
systemctl stop firewalld.service
systemctl disable firewalld.service
systemctl status firewalld
```

命令含义：

| 命令 | 作用 |
| --- | --- |
| `systemctl stop firewalld.service` | 停止防火墙 |
| `systemctl disable firewalld.service` | 禁止防火墙开机自启 |
| `systemctl status firewalld` | 查看防火墙状态 |

### 4. 关闭 SELinux

编辑配置文件：

```bash
vim /etc/selinux/config
```

将：

```text
SELINUX=enforcing
```

修改为：

```text
SELINUX=disabled
```

> 修改 SELinux 后，建议重启系统让配置完全生效。

### 5. 配置时间同步

安装 NTP：

```bash
yum install -y ntp
```

编辑配置文件：

```bash
vim /etc/ntp.conf
```

添加时间服务器：

```text
server cn.pool.ntp.org
server ntp1.aliyun.com
```

重启 NTP 服务，并关闭 `chronyd`：

```bash
systemctl restart ntpd.service
systemctl disable chronyd.service
```

修改时区为上海：

```bash
ln -sf /usr/share/zoneinfo/Asia/Shanghai /etc/localtime
```

设置 NTP 开机自启：

```bash
chkconfig ntpd on
systemctl enable ntpd.service
```

查看当前时间：

```bash
date
```

## 五、安装 JDK

### 1. 上传 JDK 安装包

将 `jdk1.8.0_111.tar.gz` 上传到服务器，例如上传到 `/opt/soft` 目录。

### 2. 解压 JDK

```bash
tar -zxf jdk1.8.0_111.tar.gz -C /opt/soft
```

### 3. 配置 Java 环境变量

编辑系统环境变量：

```bash
vim /etc/profile
```

在文件末尾添加：

```bash
export JAVA_HOME=/opt/soft/jdk1.8.0_111
export PATH=$PATH:$JAVA_HOME/bin
```

让环境变量生效：

```bash
source /etc/profile
```

### 4. 验证 JDK

```bash
java -version
```

如果能看到 Java 版本信息，说明 JDK 安装成功。

## 六、配置 SSH 免密登录

### 1. 登录本机并生成 `.ssh` 目录

```bash
ssh node01
ls -a ~/.ssh
```

### 2. 生成密钥对

```bash
ssh-keygen -t rsa -P "" -f ~/.ssh/id_rsa
```

### 3. 将公钥加入授权文件

```bash
cat ~/.ssh/id_rsa.pub >> ~/.ssh/authorized_keys
```

### 4. 测试免密登录

```bash
ssh node01
```

如果不需要输入密码即可登录，说明 SSH 免密配置成功。

## 七、安装 Hadoop

### 1. 创建安装目录

```bash
mkdir /opt/bigdata
```

### 2. 解压 Hadoop

```bash
cd /opt/soft
tar -zxf hadoop-2.7.3.tar.gz
mv hadoop-2.7.3 /opt/bigdata
```

### 3. 配置 Hadoop 环境变量

编辑 `/etc/profile`：

```bash
vim /etc/profile
```

添加：

```bash
export HADOOP_HOME=/opt/bigdata/hadoop-2.7.3
export PATH=$PATH:$JAVA_HOME/bin:$HADOOP_HOME/bin:$HADOOP_HOME/sbin
```

让配置生效：

```bash
source /etc/profile
```

## 八、修改 Hadoop 配置文件

进入 Hadoop 配置目录：

```bash
cd $HADOOP_HOME/etc/hadoop
```

也可以使用完整路径：

```bash
cd /opt/bigdata/hadoop-2.7.3/etc/hadoop
```

### 1. 修改 `hadoop-env.sh`

```bash
vim hadoop-env.sh
```

将：

```bash
export JAVA_HOME=${JAVA_HOME}
```

修改为：

```bash
export JAVA_HOME=/opt/soft/jdk1.8.0_111
```

### 2. 修改 `core-site.xml`

```bash
vim core-site.xml
```

添加 HDFS 默认访问地址：

```xml
<configuration>
  <property>
    <name>fs.defaultFS</name>
    <value>hdfs://node01:9000</value>
  </property>
</configuration>
```

### 3. 修改 `hdfs-site.xml`

```bash
vim hdfs-site.xml
```

添加以下配置：

```xml
<configuration>
  <property>
    <name>dfs.replication</name>
    <value>1</value>
  </property>

  <property>
    <name>dfs.namenode.name.dir</name>
    <value>/var/bigdata/hadoop/local/dfs/name</value>
  </property>

  <property>
    <name>dfs.datanode.data.dir</name>
    <value>/var/bigdata/hadoop/local/dfs/data</value>
  </property>

  <property>
    <name>dfs.namenode.secondary.http-address</name>
    <value>node01:50090</value>
  </property>

  <property>
    <name>dfs.namenode.checkpoint.dir</name>
    <value>/var/bigdata/hadoop/local/dfs/namesecondary</value>
  </property>
</configuration>
```

配置含义：

| 配置项 | 作用 |
| --- | --- |
| `dfs.replication` | 文件块副本数，单机环境设置为 `1` |
| `dfs.namenode.name.dir` | NameNode 元数据目录 |
| `dfs.datanode.data.dir` | DataNode 数据目录 |
| `dfs.namenode.secondary.http-address` | SecondaryNameNode Web 地址 |
| `dfs.namenode.checkpoint.dir` | SecondaryNameNode 检查点目录 |

### 4. 修改 `slaves` 文件

```bash
vim slaves
```

将 DataNode 节点设置为：

```text
node01
```

## 九、初始化并启动 HDFS

### 1. 初始化 NameNode

```bash
hdfs namenode -format
```

初始化后会创建 NameNode 元数据目录，并生成初始的 `FsImage` 文件：

```text
/var/bigdata/hadoop/local/dfs/name/current
```

> `hdfs namenode -format` 只需要执行一次。重复格式化可能导致元数据不一致。

### 2. 启动 HDFS

```bash
start-dfs.sh
```

### 3. 查看 Java 进程

```bash
jps
```

正常情况下可以看到类似进程：

```text
NameNode
DataNode
SecondaryNameNode
```

## 十、配置 Windows 主机名映射

如果需要在 Windows 浏览器访问 Hadoop Web 页面，可以修改 hosts 文件：

```text
C:\Windows\System32\drivers\etc\hosts
```

添加节点映射：

```text
192.168.243.11 node01
192.168.243.12 node02
192.168.243.13 node03
192.168.243.14 node04
```

> 如果只做单机伪分布式，保留 `node01` 即可，其他节点可以不配置。

## 十一、通过 Web 页面查看 Hadoop

NameNode 页面：

```text
http://node01:50070
```

如果主机名无法访问，可以使用 IP 地址：

```text
http://192.168.243.11:50070
```

SecondaryNameNode 页面：

```text
http://node01:50090
```

## 十二、关闭 HDFS

```bash
stop-dfs.sh
```

## 总结

Hadoop 单机伪分布式安装可以按下面顺序排查：

1. 先保证虚拟机网络正常。
2. 设置主机名和 hosts 映射。
3. 关闭防火墙和 SELinux。
4. 配置 JDK 和 Hadoop 环境变量。
5. 配置 SSH 免密登录。
6. 修改 Hadoop 核心配置文件。
7. 初始化 NameNode 并启动 HDFS。
8. 使用 `jps` 和 Web 页面验证服务状态。

这样整理后，每一步的命令、配置和验证方式都比较清楚，后面复习或排错会方便很多。
